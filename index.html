Local LLM Setup

Follow these steps to run the Llama 3.1 model locally with Interview Prep Buddy.

Checking Ollama on this device...

1

Install Ollama

Follow the instructions on the Ollama website to install Ollama on your device.

2

Download the model

Pull the model to your device:

ollama pull llama3.1:8b
3

Authorize Interview Prep Buddy

Allow the origin where you opened the app in Ollama's OLLAMA_ORIGINS setting:

setx OLLAMA_ORIGINS "https://www.interview-prep.online"

Keep any existing origins in the value. On Windows, fully quit Ollama from the system tray and restart it after changing this setting.

4

Restart Ollama

Fully quit Ollama from your system tray, then restart it.
